## Review Focus

1. **A body with `\r\n` line endings, trailing spaces before a moved read, or a `\` already there:** migrating it twice writes nothing more, and the comparison still explains it. Tasks A3, A5.
2. **A block read behind a Markdown marker** (`- {{ node.plan.content }}`, `> {{ … }}`, `**Plan:** {{ … }}`) or after an indent only: the first three are refused with the sentence and the line, the last is accepted, and nothing throws. Task A4.
3. **A link whose scheme is disguised** (`JAVASCRIPT:`, a tab or a line ending inside the scheme, `javascript&colon;`, a reference-style definition, an image): it is written as text on both surfaces of both pipelines; `/path`, `#x`, `//host` and `mailto:` stay links. Task B2.
4. **A reference to a 31 job's deliverable that is blocked, held, skipped, dropped, or another account's:** the start is refused with the right sentence and no text of it reaches an input. Task B3.
5. **A signature that is one line, ends with a line ending, has only blank-line breaks, or already ends its lines with `\`:** the owners' list says nothing for it, and the Profile preview shows it as the letter will. Tasks B5, C1.
