An object deliverable (format section_plan) is its one value, {{ node.plan.value }}, written as RFC 8785 canonical JSON (members sorted, no white space) with no final line end: the template's own final line end is not written (chapter 6 § 6.6.4). The value is written by the canonicalisation, not rendered by Scriban.

package/ is the upload, byte for byte; entry.txt names the entry composed (deliverable.note). Composing it over scope.json (the data, keys rooted as the run holds them), with each placement decided as placed.json says (a site it does not name is not placed), gives expected.txt byte for byte: Scriban 7.2.5, the invariant culture, strict variables.
