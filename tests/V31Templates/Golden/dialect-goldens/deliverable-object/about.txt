An object deliverable (format section_plan) is its one value, {{ node.plan.value }}, written as RFC 8785 canonical JSON (members sorted, no white space) with no final line end: the template's own final line end is not written (chapter 6 § 6.6.4).

package/ is the upload, byte for byte; entry.txt names the entry composed (deliverable.note). Its format is an object format, so its text is the RFC 8785 JSON of the value scope.json holds at the one path its template reads, with no final line end: expected.txt byte for byte. placed.json is empty: an object deliverable places nothing.
